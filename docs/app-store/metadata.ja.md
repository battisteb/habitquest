## Description (4000)
毎日の習慣を、壮大なクエストに。

HabitQuestは、続けることを冒険に変えるドット絵の習慣トラッカーです。クエストを達成して連続記録をつなぎ、XPとゴールドを稼ぎ、きみと一緒に成長するヒーローをレベルアップさせよう。1日の様子で色が変わる小さなスライム「ピップ」が、最初のクエストから案内します。

⚔️ クエスト — 習慣はすべてクエスト。毎日、選んだ曜日だけ、週に数回などの頻度を選べます。達成するとXPとゴールドがもらえます。

🔥 やさしい連続記録 — うっかり忘れた日は、週1回のフリーズが自動でカバー。連続記録が途切れても、ペナルティはなし。戻ってきた日はXPが2倍になり、途切れたばかりの連続記録は修復もできます。

📜 デイリーミッション — 毎日3つの新しいチャレンジと、受け取れる報酬。

👹 今週のボス — 毎週、悪い習慣がモンスターに。スヌーズゴーレム、ドゥームスクロール・クラーケン、ソファのトロール…。クエストを達成するたびにダメージ。日曜日までに倒そう。

🧙 きみのヒーロー — 見習いから伝説へレベルアップ。ランクごとに見た目が変わり、ショップの帽子・服・アクセサリーで着せ替えもできます。

🏟️ アリーナ — 毎日、達成したクエストがきみの攻撃力になり、同じリーグのプレイヤーと戦います。シーズンごとにリーグを上がろう。

🤺 バトルとチームチャレンジ — フレンドにターン制バトルを挑んだり、最大3人のフレンドと共通の目標に挑戦したり。

🎯 集中モード — 試験、大会、旅行、体調不良のときは、一部のカテゴリーをお休みに。連続記録は失われません。

📊 統計 — ドットで見る1年、達成率、今日の気分、そしてきみを元気にする習慣がわかるパーソナルな分析。

👑 プレミアム（任意）— 全期間の統計、追加の連続記録フリーズ、連続記録とともに育つドット絵のドラゴン、毎月の限定アイテム、48時間以内の優先サポート、広告なし。月額・年額・買い切りから選べます。課金で強くなることはありません：強さは習慣から生まれます。

運動、睡眠、勉強、マインドフルネス、食事、仕事術など、続けたいことなら何でも。
