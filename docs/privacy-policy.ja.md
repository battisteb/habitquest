# HabitQuest — プライバシーポリシー

*最終更新日：2026年10月7日*

*この日本語版は[英語版](privacy-policy)の翻訳です。内容に相違がある場合は英語版が優先します。*

HabitQuest（以下「本アプリ」）は **Battiste Boungo**（以下「当方」）が提供しています。本ポリシーでは、本アプリが収集するデータ、その目的、そしてあなたが選べることを説明します。お問い合わせ：**batto060504@gmail.com**

## 1. 収集するデータ

| データ | 目的 | 保存先 |
|---|---|---|
| メールアドレスとパスワード（ハッシュ化） | アカウントの作成と保護 | Supabase（認証） |
| 「Googleで続ける」を選んだ場合：Googleから提供されるメールアドレス、名前、プロフィール画像のリンク | アカウントの作成とログイン（保存するのはメールアドレスのみで、Googleの名前や画像はアプリで使いません） | Supabase（認証） |
| ユーザー名、アバターの色、レベル、XP、ゴールド、装備アイテム | ゲームの運営と、フレンドへのヒーローの表示 | Supabase |
| 習慣、達成記録、連続記録、任意のメモ | 習慣トラッキングの基本機能 | Supabase、および端末内のキャッシュ |
| 今日の気分（1〜5、記録した場合のみ） | 気分がよくなる習慣を、あなた自身の統計で表示するため。共有したり他人に見せたりすることはありません | Supabase |
| フレンド、バトル、チャレンジ、アプリ内のお知らせ | ソーシャル機能 | Supabase |
| タイムゾーン（例：Asia/Tokyo）とアプリの言語 | あなたの現地時間で連続記録や1日の上限を数えるため。あなたの言語で通知やメールを送るため | Supabase |
| 最後に使ったプラットフォーム（Web、iPhone、Android）とアプリを最後に開いた日時 | 全体の利用統計のため（例：Androidのプレイヤー数）。他のプレイヤーに見せることはありません | Supabase |
| プッシュ通知のトークン | リマインダーやゲームのお知らせを送るため | Supabase |
| サポートへのメッセージ（アプリのバージョン、端末の種類、言語を含む） | お返事と不具合の修正 | Supabase |
| gethabitquest.comでウェイトリストに登録した場合のみ：メールアドレス、サイトの言語、同意 | アプリの公開時にメールを1通送るため | Supabase |
| 購入履歴とサブスクリプションの状態 | プレミアムの有効化 | RevenueCat、Apple / Google |
| 広告ID（IDFA / Androidの広告ID）— **トラッキングを許可した場合のみ** | 無料ユーザーへの広告表示 | Google AdMob |

アプリやサイトでエラーが起きたときは、修正のために技術的なレポートをSentryに送ります（エラーの内容とコード上の発生場所、アプリのバージョン、端末またはブラウザの機種、OS）。このレポートには名前、メールアドレス、習慣、メッセージは含まれません（個人データの収集はオフにしています）。分析ツールのSDKは使っておらず、データを販売することもありません。

## 2. 広告とトラッキング

無料ユーザーにはGoogle AdMobの広告が表示されます。iOSでは、パーソナライズ広告の前に許可を求めます（App Tracking Transparency）。許可しない場合は、パーソナライズされていない広告のみが表示されます。プレミアム会員には広告は表示されません。[Googleのプライバシーポリシー](https://policies.google.com/privacy)もご覧ください。

## 3. 委託先

- **Supabase** — データベース、認証、サーバー機能（[プライバシー](https://supabase.com/privacy)）
- **RevenueCat** — サブスクリプション管理（[プライバシー](https://www.revenuecat.com/privacy)）
- **Google AdMob** — 広告（[プライバシー](https://policies.google.com/privacy)）
- **Sentry** — エラー・クラッシュのレポート、EU内で保存（[プライバシー](https://sentry.io/privacy/)）
- **Expo** — プッシュ通知の配信とウェブサイトのホスティング（[プライバシー](https://expo.dev/privacy)）
- **Resend** — パスワード再設定などアカウント関連のメール（[プライバシー](https://resend.com/legal/privacy-policy)）
- **Apple / Google** — App StoreとGoogle Playでの支払い
- **Google** — ログイン（「Googleで続ける」を選んだ場合のみ）（[プライバシー](https://policies.google.com/privacy)）

## 4. 誰があなたのデータを見られるか

他のプレイヤーはユーザー名であなたを検索し、公開プロフィール（ユーザー名、アバターと装備アイテム、レベル、XP、ランク、ゴールド、最高連続記録、登録日）を見ることができます（全体ランキング、フレンド検索）。フレンドはあなたのバトルやチャレンジの結果も見られます。習慣、メモ、タイムゾーン、サブスクリプション、サポートへのメッセージは非公開です。

## 5. 保存期間と削除

データはアカウントがある間保存します。ウェイトリストのメールアドレスは公開時のメール1回だけに使い、その後削除します。それより前に削除を依頼することもいつでもできます。**設定 → アカウントを削除** からいつでもアカウントを削除でき、アカウントと関連するすべてのデータがサーバーから完全に消去されます。有効なサブスクリプションは、App StoreまたはGoogle Playの設定で別途解約してください。

## 6. あなたの権利

GDPRおよび同様の法律に基づき、あなたはデータへのアクセス、訂正、エクスポート、削除、および処理への異議申し立てができます。**batto060504@gmail.com** までご連絡ください。お住まいの国のデータ保護当局（日本では個人情報保護委員会、フランスではCNIL）に苦情を申し立てることもできます。

## 7. 子ども

HabitQuestは13歳未満（韓国では個人情報保護法により14歳未満）の子どもを対象としておらず、意図的にそのデータを収集することはありません。
