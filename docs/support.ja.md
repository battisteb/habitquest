# HabitQuest — サポート

## お問い合わせ

- **アプリから**：設定 → 💬 サポート。種類（不具合、アイデア、その他）を選んでメッセージを書いてください。既読になったとき、対応したときに表示されます。
- **メールで**：[habitquest.application@gmail.com](mailto:habitquest.application@gmail.com)。ユーザー名、スマホの機種、問題の直前に何をしたかをお知らせください。

すべてのメッセージに目を通し、通常は数日以内にお返事します。**プレミアム会員**には優先して48時間以内にお返事します。

## よくある質問

**パスワードを忘れました。** ログイン画面でメールアドレスを入力し、「パスワードを忘れた？」をタップしてください。新しいパスワードを決めるためのリンクが届きます。

**連続記録が途切れました。** うっかり忘れた日は、週1回のフリーズ（またはフリーズトークン）が自動で使われます。それでも途切れた場合、ペナルティはありません。戻ってきてから24時間はXPが2倍になり、途切れてから48時間以内なら連続記録を修復できます（ゴールド、または無料プレイヤーは1日1回の広告で）。集中モード（設定 → 集中モード）を使えば、試験・旅行・体調不良のあいだ一部のカテゴリーをお休みにできます。

**プレミアムを購入したのに反映されません。** プレミアム画面で「購入を復元」をタップしてください。購入時と同じAppleまたはGoogleアカウントを使ってください。

**プレミアムを解約するには？** サブスクリプションはAppleまたはGoogleが管理しています。iPhone：設定 → ユーザー名 → サブスクリプション。Android：Google Play → お支払いと定期購入 → 定期購入。アプリを削除しても解約にはなりません。

**アカウントを削除するには？** 設定 → アカウントを削除。アカウントとすべてのデータが完全に消去されます（[プライバシーポリシー](privacy-policy.ja)をご覧ください）。
