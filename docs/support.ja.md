# HabitQuest — サポート

## お問い合わせ

- **アプリから**：設定 → 💬 サポート。種類（問題、アイデア、その他）を選んでメッセージを書いてください。私たちが読んだとき、対応したときがわかります。
- **メールで**：[habitquest.application@gmail.com](mailto:habitquest.application@gmail.com)。ユーザー名、スマートフォンの機種、問題が起きる直前に何をしたかを書いてください。

すべてのメッセージを読み、通常は数日以内に返信します。**プレミアム会員**には優先的に、48時間以内に返信します。

## よくある質問

**パスワードを忘れました。** ログイン画面でメールアドレスを入力し、「パスワードを忘れた？」をタップしてください。新しいパスワードを設定するためのリンクが届きます。

**連続記録が途切れました。** その日（あなたの現地日付）にクエストを達成しないと、連続記録は途切れます。無料プレイヤーは週に1回フリーズ（休息日）を使えます。集中モード（設定 → 🎯 集中モード）を使うと、試験・休暇・体調不良の間は一部のカテゴリーが一時停止され、連続記録は消えずに凍結されます。

**プレミアムを購入したのに反映されません。** プレミアム画面で「購入を復元」をタップしてください。購入時と同じ Apple または Google のアカウントを使ってください。

**プレミアムを解約するには？** サブスクリプションは Apple または Google が管理しています。iPhone：設定 → あなたの名前 → サブスクリプション。Android：Google Play → お支払いと定期購入 → 定期購入。アプリを削除してもサブスクリプションは解約されません。

**アカウントを削除するには？** 設定 → アカウントを削除。アカウントとすべてのデータが完全に消去されます（[プライバシーポリシー](privacy-policy.ja)を参照）。
